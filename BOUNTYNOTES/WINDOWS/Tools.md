# Windows Tools

| Tool | Command | Purpose |
|---|---|---|
| Full System Configuration | `msconfig.exe` | Configure startup, boot, and services |
| Control Panel | `control.exe` | Classic Windows settings panel |
| Windows Information | `msinfo32.exe` | Detailed system information |
| Computer Management | `compmgmt.msc` | Central console for disks, services, users, etc. |
| Resource Monitor | `resmon.exe` | Live CPU/memory/disk/network monitoring |
| Windows Defender (Threat Settings) | `windowsdefender://threatsettings` | Opens Defender's threat protection settings |
| Microsoft Defender SmartScreen | `windowsdefender://appbrowser` | Opens SmartScreen app/browser settings |
| Windows Firewall | `WF.msc` | Windows Firewall with Advanced Security |
| Registry Editing | `regedit.exe` / `regedt32.exe` | Edit the Windows Registry |
| Volume Shadow Copy Service | `SystemPropertiesProtection.exe` | System Protection / restore point settings |
| IP Configuration | `ipconfig /all` | Full detailed network configuration |
| Remote Desktop | `mstsc` | Launches Remote Desktop Connection |
| Group Policy Management | *(Default Domain Policy)* | Manage domain-wide policy settings |
| Force Group Policy Update | `gpupdate /force` | Immediately re-applies Group Policy |
